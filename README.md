# KiCad Footprint for DFRobot DFR1202 / CKCS CK2416 DC-DC Converter

This is a KiCad footprint for the DFRobot DFR1202 or CKCS CK2416 DC-DC Converter. Thie footprint allows the module to be soldered to a carrier PCB as a surface mount device.
